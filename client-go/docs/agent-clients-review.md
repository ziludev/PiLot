## 2. 挑的标准

一条：**能不能省掉 alex 真会跑的一步。** 加一个按钮不算成绩，少一次复制粘贴才算。另外两条硬约束：pi-durable 里得真有这个数据（没有就是假功能），而且不引第三方 UI 库——Go + mygo 手写。

## 3. 这轮搬进来的

### 3.1 ⌘K 命令面板（参考 Linear / VS Code / crush 的 `Ctrl+P`）
侧栏会话多了以后，「找到上周那个会话」要走：滚侧栏 → 展开分组 → 读标题。现在 ⌘K 一个框：打字即筛（会话标题 + 动作，中英都能搜），↑↓ 走、⏎ 开、esc 关，鼠标点也行。

- 匹配是子序列打分：词首字母、连续字母加分，短标题胜过长标题。所以 `dc` 能找到 `Deploy checklist for the 0.4 train`。
- 动作就是侧栏那些按钮背后的同一个函数（新建会话、查找、导出、跳最新、改动、记忆、项目、设置、重启 agent），面板不会和界面走散。
- 入口：⌘K，或侧栏搜索框右边那个 `⌘K` 小标（键盘提示放在它替代的那个框里）。

### 3.2 快捷键
⌘K 命令面板、⌘J 跳到最新、⌘⇧E 导出当前会话。都在面板里标了键位——用得久了自然会离开面板。

### 3.3 拖任何文件进来 → 路径进输入框
以前拖一个 pdf、一个 `.log`、一个超过 200KB 的文本、一个目录进来，得到的是红字「只收图片和文本文件」。可 agent 就在这台机器上跑，什么都能读——拒绝只是让 alex 自己去复制路径。

现在：图片照旧当附件、小文本照旧整段引进来（这两条本来就好用，不许退），其余的把这个文件的绝对路径放进输入框（带空格用反引号包住），配一句轻提示。这是参考 claudecodeui / crush 那种「文件已经在这台机器上」的姿势，而不是 Web 聊天那种「必须先上传」。

### 3.4 导出当前会话为 Markdown（参考 assistant-ui 的 thread 导出）
`~/Downloads/PiLot-<标题>-<年月日-时分>.md`：标题、时间、每轮「你 / PiLot」的原话，中间的步骤折在 `<details>` 里（工具名 + 它拿什么参数跑的），工具输出不带走——那是最长的部分，也是最少被引用的部分。给 PR、issue、不在场的人用。

### 3.5 顺带：提示分两种颜色
导出成功不该长得像报错。提示行现在分「消息」（灰 + 勾）和「问题」（红 + 三角）。

## 4. 看了但没做的，和为什么

| 想要 | 为什么不做 |
| --- | --- |
| `BranchPicker`（回答的分支选择、重新生成的多个候选） | pi-durable 里一轮回答只有一份，没有候选分支的数据结构。做出来只能是一个假的箭头。 |
| `Reasoning` / `ChainOfThought` 折叠 | 客户端已经有等价物：entries 里的 thinking 会在步骤折叠里算作一步（实测最近 300 个版本里没有，因为我们的模型不产 reasoning；有数据就会出现）。再做一个专门的折叠块，是为了一个常年空着的区域写代码。 |
| `Suggestion`（回答下面的后续建议） | 得再调一次模型生成，bridge 没有这条通道；客户端自己编建议就是编事实。 |
| `Dictate` 口述、`SelectionToolbar` 划词引用 | mygo 没有麦克风与文本选区原语。 |
| 并发多会话面板（vibe-kanban 那种） | 一条会话一个 run，没有并发数据可画。 |
| `CompactContext`（压缩上下文） | pi-durable 的上下文裁剪在引擎里，客户端只能显示用量；要暴露成按钮得先有「手动压缩」这个动作。 |
| 侧栏按项目分组 / 置顶 | 现在的分组（进行中 / 群聊 / 话题 / 其他）已经覆盖了「找得到」这件事，⌘K 又把最贵的那一步（翻找）拿掉了。留给下一轮。 |

headless 渲染确认过面板真的画出来了（框、行、选中底色、底部键位说明），侧栏搜索框右边的 ⌘K 小标也确认不压边框。

## 5.5 第二轮：又搬了三件

第一轮之后接着做的，都是「省掉一步」里排得最靠前的：

1. **⌘P 跳到文件**（VS Code / crush 的 `Ctrl+P`）。列表来自 `git -C <checkout> ls-files -z --cached --others --exclude-standard`：既包含已跟踪的，也包含未跟踪但没被忽略的——正是 agent 能改到的范围；不是目录遍历，所以 `node_modules`、`dist` 不会淹掉结果。没有 git 的目录退化成受限深度的遍历。⏎ 把绝对路径写进输入框（和拖文件同一条路）。
2. **置顶 + 按项目分组**。置顶是一块永远排在最上面的架子，钉住的聊天不会被时间折进「已归档」；它只存在本机 `prefs.json`，不写进 bridge。分组在「按来源 / 按项目」之间切，切完项目名就是标题，没有项目的聊天落进「其他」（默认折叠）。
3. **快捷键表 ⌘⇧/ 和导出 HTML**。五个键够用也够忘，能叫出来比烫在界面上便宜；HTML 和 Markdown 同名不同后缀，样式内联、双击能读、能直接发人。

顺手修的两处：命令面板的选中行原来用主题里的浅灰 accent，在白底上几乎看不见，改成蓝色 selection 底 + 细边；`paletteMaxRows` 从 12 抬到 14 —— 动词已经 13 个，压到 12 会让最后一个动词在空查询下永远够不着。

**关于上下文用量条（原候选 4）**：查过数据了，做不了真数。pi-durable 存下来的 assistant entry 里没有 `usage`（最近 300 个 revision 里 0 命中），`pi.usage` 是按模型累加的总额，不是「这一轮的 prompt 有多大」。要显示「离压缩还有多远」，得在引擎侧把每轮 prompt tokens 落下来——不是客户端能编的，编出来就是假数字。先挂着。

## 6. 下次可以接的
